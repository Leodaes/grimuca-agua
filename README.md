# Grimuca Agua

Mide el agua de tu casa con una tira reactiva y una foto. La aplicación lee la tira, explica cada parámetro con un semáforo y sugiere el cartucho de filtro que corresponde. Los pedidos se despachan desde las tiendas de Grimuca y aparecen en vivo en el panel del operador.

Proyecto del Hackatón ValenValley 2026, track Logística.

Demo: https://agua.oydo.app
